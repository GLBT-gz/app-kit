# 数据系统使用规范

> 共享前端数据层（@appkit/ui）规范：localStorage / 文件 / SQLite 三类存储的声明、读写与统一管理。

> **速读卡（AI 必读）**：
> ① 所有数据必须在 `data.ts` 注册，`namespace` 必填（防跨项目 key 冲突）；
> ② localStorage 用 `useData` 读写，禁止直接 `getItem`/`setItem`；
> ③ 文件/数据库须 `registerDataItems`/`registerDbSelect`/`registerDbExecute` 注册；
> ④ 缓存类用 `default: null`，由消费者首次写入，不要在注册时初始化。

## 一、数据类型

系统有 3 种存储后端，通过注册声明统一管理：

| 类型 | 用途 | 存储位置 | 示例 |
|------|------|---------|------|
| **localStorage** | UI 状态、用户偏好、缓存 | 浏览器内置存储 | 当前 Tab、面板宽度、店铺排序 |
| **文件 (file)** | 需要加密或结构化的数据 | `app_data_dir`（Rust 后端目录） | 账号凭证、店铺缓存 |
| **数据库 (db)** | 业务数据、大批量结构化数据 | `app_data_dir/*.db`（SQLite） | 备货结果、SKU 数据 |

## 二、声明数据 —— `data.ts`

每个项目在 `src/data.ts` 中统一声明所有数据项：

```typescript
import { defineDataStore, registerDbSelect, registerDbExecute } from "@appkit/ui";
import { getDb } from "./utils/db";

export const store = defineDataStore({
  version: "1.0.0",
  namespace: "003",                    // ← 必填！不同项目不同值，避免 key 冲突
  categories: {                         // 分类定义
    config:     { label: "业务配置",   onDelete: "warn" },
    preference: { label: "用户偏好",   onDelete: "allowed" },
    cache:      { label: "界面缓存",   onDelete: "allowed" },
    transient:  { label: "临时状态",   onDelete: "allowed" },
    database:   { label: "业务数据",   onDelete: "warn" },
  },
  items: {
    // key 自动加上 namespace 前缀（如 "003-active-tab"）
    "active-tab":        { storage: "localStorage", category: "transient", default: "home" as string, desc: "当前活动 Tab" },
    "left-width":        { storage: "localStorage", category: "transient", default: 340, desc: "左面板宽度" },
    "auto-mode":         { storage: "localStorage", category: "preference", default: "api" as string, desc: "自动化模式" },
    "shop-order":        { storage: "localStorage", category: "preference", default: [] as string[], desc: "店铺排序" },
    "shop-summaries":    { storage: "localStorage", category: "cache",      default: null, desc: "店铺摘要缓存" },
  },
  databases: {                          // SQLite 数据库注册
    "reorder-stock": {
      storage: "db",
      category: "database",
      desc: "返单备货量数据库",
      dbFile: "reorder-stock.db",
      onDelete: "warn",
    },
  },
});

// 数据库查询/执行函数注册（DataManager 复用前端 SQLite 连接）
registerDbSelect("reorder-stock.db", async (sql, params) => {
  const db = await getDb();
  return db.select(sql, params ?? []);
});
registerDbExecute("reorder-stock.db", async (sql, params) => {
  const db = await getDb();
  return db.execute(sql, params ?? []);
});
```

### 规则

1. **`namespace` 必须设置**，否则多个项目在同一浏览器中 key 会冲突
2. **`default: null`** 的项不会自动写入 localStorage，由代码首次使用时写入
3. **`default: {}`**（空对象）的项也不会自动写入，由消费者代码首次写入完整值
4. **`category`** 影响 DataManager 面板中的分组和删除行为
5. **数据库文件**须注册 `registerDbSelect`/`registerDbExecute`，让 DataManager 复用前端 SQLite 连接，避免锁竞争

## 三、读写数据

### 3.1 localStorage 数据 —— `useData`

```typescript
import { useData } from "@appkit/ui";
import { store } from "./data";

function MyComponent() {
  // 自动从 localStorage 初始化，修改时自动持久化
  const [activeTab, setActiveTab] = useData(store.keys["active-tab"]);
  //            ↑ 类型自动推断为 string
  //                         ↑ 可传新值或 updater 函数
  //                                    ↑ reset() 删除 key，恢复默认值

  // 带复杂类型的值
  const [shopOrder, setShopOrder] = useData(store.keys["shop-order"]);
  // shopOrder 自动推断为 string[]

  return (
    <button onClick={() => setActiveTab("home")}>
      {activeTab}
    </button>
  );
}
```

**禁止**直接使用 `localStorage.getItem/setItem` 读写已注册的 key。

### 3.2 文件数据 —— Rust API（当前做法）

文件数据（凭证、店铺缓存）通过 Rust 后端 API 读写：

```typescript
import { saveTemuCredentials, loadTemuCredentials } from "../api";

const creds = await loadTemuCredentials();
await saveTemuCredentials({ ... });
```

文件项在 `data.ts` 中通过 `registerDataItems` 注册，以便 DataManager 可识别和管理：

```typescript
registerDataItems("1.0.0", {
  database: { label: "业务数据", onDelete: "warn" },
}, {
  "credentials.json": { storage: "file", category: "database", desc: "平台凭证", onDelete: "warn" },
  "shop_cache.json":  { storage: "file", category: "database", desc: "Temu 店铺缓存", onDelete: "allowed" },
});
```

### 3.3 数据库数据 —— DAO 层

每个项目在自己 `utils/db.ts` 中封装 DAO 函数：

```typescript
import { getDb, saveTemuGzResults, loadTemuGzTableData } from "../utils/db";

// getDb() 返回 tauri-plugin-sql 的 Database 实例（单例）
const db = await getDb();
const rows = await db.select("SELECT * FROM \"temu广州\"");
```

## 四、DataManager 面板

每个项目的设置页都有一个「数据管理」Tab，对所有已注册数据提供统一管理：

| 功能 | 说明 |
|------|------|
| **浏览器存储 Tab** | 列出所有注册的 localStorage key，可查看值、删除 |
| **本地文件 Tab** | 列出所有注册的文件和数据库，可展开查看表结构、清空、删除 |
| **删除行为** | `allowed` 直接删 / `warn` 弹确认 / `blocked` 不可删 |

## 五、App.tsx 数据初始化

```typescript
import { store } from "./data";

export default function App() {
  // 使用 useData 持久化 Tab 状态
  const [activeTab, setActiveTab] = useData(store.keys["active-tab"]);
  const [selectedCardKeys, setSelectedCardKeys] = useData(store.keys["selected-card-keys"]);

  // 初始化 SQLite 数据库
  useEffect(() => {
    ensureDb().catch(console.error);
  }, []);

  // 旧数据迁移（仅首次触发）
  useEffect(() => {
    if (selectedCardKeys.length === 0) {
      // 从旧 key 读取并迁移到带 namespace 的新 key
      const oldVal = localStorage.getItem("old-key");
      if (oldVal) {
        localStorage.setItem("003-new-key", oldVal);
        localStorage.removeItem("old-key");
      }
    }
  }, []);

  // 传 AppLayout 属性
  const tabBar = <TabBar activeTab={activeTab} onTabChange={setActiveTab} disabled={settingsOpen} />;
  const handleTopBarWheel = tabWheelHandler(activeTab, setActiveTab);

  return (
    <AppLayout settingsTabs={tabs} onSetWindowPin={setWindowPin} tabBar={tabBar} onTopBarWheel={handleTopBarWheel}
      onSettingsChange={setSettingsOpen} openSettingsTo={openSettingsTo}>
      ...
    </AppLayout>
  );
}
```

## 六、关键规范总结

1. **所有数据必须在 `data.ts` 中注册**，不允许项目自行直接操作 localStorage / 文件 / 数据库而不注册
2. **`namespace` 必须设置**，避免跨项目 key 冲突
3. **数据通过 `useData` 读写**，不要直接调用 `localStorage.getItem/setItem`
4. **缓存类数据用 `default: null`**，由消费者首次写入，不要在注册时初始化
5. **旧数据迁移**写在 `App.tsx` 的 `useEffect` 中，迁移完删除旧 key
6. **新建项目时**：复制模板 → 改 `namespace` → 定义 `data.ts` → `App.tsx` 引入 `store`
